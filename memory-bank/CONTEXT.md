# Contexto del producto

> Pendiente de aprobación. No tratar las propuestas como identidad corporativa confirmada.

## Producto y público
Prototipo académico de una tienda de moda para personas que buscan prendas contemporáneas con una experiencia de navegación clara y editorial. El briefing no concreta segmentos, edad, líneas de producto ni posicionamiento comercial; estos supuestos deberán confirmarse.

## Identidad conceptual
Dirección de arte sugerida: moda francesa premium, elegante, minimalista y contemporánea; marfil cálido, grafito, borgoña y grises cálidos, fotografía editorial consistente y abundante espacio. El nombre de marca/logo oficial está pendiente. Usar un marcador claramente reemplazable (p. ej. “MAISON [NOMBRE]”) solo tras aprobación; nunca presentarlo como nombre real.

## Experiencia deseada
Navegación sencilla entre cinco vistas, jerarquía editorial, fichas de producto comparables y controles comprensibles. La navegación es real mediante enlaces HTML. Búsqueda, filtros, carrito, cantidad y checkout se muestran como prototipo y no realizan operaciones.

## SEO
Cada vista lleva título y descripción únicos, idioma español, viewport, contenido HTML indexable, semántica, rutas internas coherentes y alt útil. JSON-LD solo con datos confirmados y congruentes con el contenido visible. No se afirman resultados enriquecidos.

## Responsive y accesibilidad
Enfoque mobile-first; validar 320, 375, 768, 1024 y 1440 px. Evitar scroll horizontal, preservar teclado, foco, contraste, zoom, etiquetas y nombres accesibles. La navegación móvil no depende de JavaScript.

## Límites del ejercicio
HTML5 + Tailwind CSS v4 + CSS adicional mínimo; Git/GitHub. Sin framework, JavaScript personalizado, API, backend ni transacciones. No almacenar ni pedir datos de tarjetas reales. No se presuponen dominio, dirección, contactos, reseñas, disponibilidad u ofertas.

## Pendientes de aprobación
Nombre/wordmark, fuentes externas o sistema, catálogo real/ficticio de muestra, rutas finales, taxonomía y tallas, precios, tratamiento fiscal, imágenes/licencias y datos de organización. Mantenerlos como marcadores o datos explícitamente ficticios de prototipo hasta su confirmación.
