# Regla: SEO y Schema.org

- Cada vista requiere `<title>` único, meta description propia, meta viewport, idioma y contenido indexable en HTML.
- Usa encabezados semánticos, enlaces internos coherentes y alt descriptivo en imágenes informativas.
- Añade JSON-LD solo cuando los datos visibles sean concretos, verdaderos y consistentes. `Organization` depende de datos confirmados; `Product` refleja el producto visible y `Offer` solo un precio/disponibilidad realmente especificados.
- No inventes dominio, razón social, dirección, contacto, redes, reseñas, puntuaciones, descuentos o disponibilidad. Marca los datos pendientes en la documentación, no los publiques como hechos.
- Valida el JSON-LD con Schema Markup Validator. La validez del marcado no garantiza resultados enriquecidos en Google.
- No afirmes resultados de Lighthouse/PageSpeed que no se hayan medido; registra herramienta, fecha, URL y resultado cuando exista evidencia.
