# Regla: responsive y accesibilidad

- Diseña mobile-first. Verifica, como mínimo, anchos de 320, 375, 768, 1024 y 1440 px.
- No debe existir scroll horizontal accidental. Usa imágenes fluidas, rejillas que colapsen y formularios utilizables en pantalla estrecha.
- En móvil, la navegación debe seguir siendo accesible sin JavaScript personalizado: prioriza enlaces visibles y disposición adaptable; no finjas un menú desplegable interactivo.
- Todas las acciones deben poder operarse por teclado y mostrar foco visible. Mantén orden de tabulación lógico y evita quitar outlines sin reemplazo.
- Comprueba contraste de texto y controles, zoom del navegador y tamaño táctil razonable. No uses solo el color para comunicar estado.
- Proporciona etiquetas, instrucciones y mensajes textuales para campos; las etiquetas no deben depender solo de placeholders.
- Comprueba que contenido, controles y foco no se recorten ni solapen en los anchos objetivo.
